## ၁။ The Subjunctive Rule (That + S + Base Verb)

အမိန့်၊ တောင်းဆိုမှု၊ အကြံပြုချက်ကို ပြသော ကြိယာများနှင့် Adjectives များ၏နောက် `that-clause` တွင် **(should) ကွယ်ပျောက်နေသဖြင့် ကတ္တား မည်သူပင်ဖြစ်စေ Base Verb (မူလကြိယာ) ကိုသာ သုံးရသည်**:

$$\mathbf{Verb / Adj} + \mathbf{that} + \mathbf{Subject} + \mathbf{[ BASE\ VERB ]}$$

### ၁။ အဓိက Verbs:
`suggest, recommend, request, demand, require, insist, ask`
- *The auditor recommended that the director [ **review** ] the files.* (reviews မဟုတ်ပါ)
- *The policy requires that each traveler [ **submit** ] receipts.* (submits မဟုတ်ပါ)

### ၂။ အဓိက Adjectives:
`essential, vital, important, imperative, mandatory`
- *It is imperative that the server [ **be** ] operational by dawn.* (is မဟုတ်ပါ)
