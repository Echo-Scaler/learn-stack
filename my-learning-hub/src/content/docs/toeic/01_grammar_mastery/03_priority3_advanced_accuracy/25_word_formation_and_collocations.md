## ၁။ အသုံးများသော Business Collocations (တွဲစကားများ)

| Collocation (ကြိယာ + နာမ်) | အဓိပ္ပာယ် | နမူနာ ဝါကျ |
| :--- | :--- | :--- |
| **meet a deadline** | သတ်မှတ်ရက် အမီပြီးမြောက်သည် | *We worked overtime to [ **meet the deadline** ].* |
| **conduct research / survey** | သုတေသန/စစ်တမ်း ကောက်ယူသည် | *The marketing team [ **conducted a survey** ].* |
| **reach an agreement** | သဘောတူညီချက် ရရှိသည် | *Both parties finally [ **reached an agreement** ].* |
| **grant approval** | ခွင့်ပြုချက် ပေးအပ်သည် | *The board [ **granted approval** ] for the budget.* |
| **address an issue** | ပြဿနာကို ဖြေရှင်းကိုင်တွယ်သည် | *We must [ **address this issue** ] immediately.* |
| **fulfill an order** | အော်ဒါကို ဖြည့်ဆည်းပေးသည် | *The warehouse [ **fulfilled the order** ] promptly.* |
