## I. Advanced Comparison and Degree

အဆင့်မြင့် အတိုင်းအတာနှင့် ဆက်စပ်နှိုင်းယှဉ်မှုများကို တိကျပြတ်သားစွာ ဖော်ပြသော သဒ္ဒါဖွဲ့စည်းပုံများ:

| Structure | Example Sentence | ရှင်းလင်းချက် |
| :--- | :--- | :--- |
| **The more ..., the more ...** | *The more you practise, the more confident you become.* | လေ့ကျင့်လေလေ၊ ပိုမိုယုံကြည်မှု ရှိလာလေလေ ဖြစ်သည်။ |
| **As ... as ever** | *She is as determined as ever.* | သူမသည် အရင်ကကဲ့သို့ပင် စိတ်ပိုင်းဖြတ်ထားဆဲ ဖြစ်သည်။ |
| **Far from + -ing** | *Far from solving the problem, the changes made it worse.* | ပြဿနာကို ပြေလည်စေဖို့ ဝေးစွ၊ အပြောင်းအလဲများက ပိုဆိုးစေခဲ့သည်။ |
| **All the more** | *His success was all the more impressive given the difficulties.* | အခက်အခဲများကို ထောက်ရှုလျှင် သူ၏ အောင်မြင်မှုသည် သာ၍ပင် အထင်ကြီးဖွယ် ဖြစ်သည်။ |
| **No less ... than** | *The discovery was no less significant than the original finding.* | တွေ့ရှိချက်သည် မူလတွေ့ရှိချက်ထက် အရေးပါမှု မလျော့နည်းခဲ့ပါ။ |
| **Not so much A as B** | *It was not so much a mistake as a misunderstanding.* | အမှားဆိုသည်ထက် နားလည်မှုလွဲမှားခြင်းသာ ဖြစ်သည်။ |
| **Rather than + verb** | *Rather than criticize, we should offer a solution.* | အပြစ်တင်နေမည့်အစား အဖြေတစ်ခုကို ကျွန်ုပ်တို့ ကမ်းလှမ်းသင့်သည်။ |
