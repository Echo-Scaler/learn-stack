## G. Advanced Relative Clauses

ရှုပ်ထွေးသော စီးပွားရေးစာပိုဒ်များတွင် အချက်အလက် ထပ်မံဖြည့်စွက်ရာ၌ အသုံးပြုသော ဆက်စပ်ဝါကျများ:

| Structure | Example Sentence | သဒ္ဒါမှတ်ချက် |
| :--- | :--- | :--- |
| **Non-defining relative clause** | *The proposal, which was submitted yesterday, has been approved.* | Comma နှစ်ခုကြား ဖြည့်စွက်အချက်အလက် (That လုံးဝ မသုံးရပါ)။ |
| **Preposition + whom** | *The colleague to whom I spoke was very helpful.* | လူအတွက် Preposition နောက်တွင် `whom` သာ လိုက်ရမည်။ |
| **Preposition + which** | *The issue about which we disagreed remains unresolved.* | အရာဝတ္ထုအတွက် Preposition နောက်တွင် `which` သာ လိုက်ရမည်။ |
| **Relative clause with whose** | *The researcher, whose findings were controversial, published another paper.* | တွေ့ရှိချက်များ အငြင်းပွားဖွယ်ဖြစ်ခဲ့သော သုတေသီ။ |
| **Sentential which** | *He rejected the offer, which surprised everyone.* | `which` သည် ရှေ့ရှိ ဝါကျတစ်ခုလုံး၏ ဖြစ်ရပ်ကို ပြန်လည်ညွှန်းဆိုသည်။ |
| **Whatever / Whoever** | *Whoever is responsible must explain what happened.* | တာဝန်ရှိသူ မည်သူမဆို ဖြစ်ပျက်ခဲ့သည်ကို ရှင်းပြရမည်။ |
