## B. Inversion — Formal and Emphatic English

Inversion ဆိုသည်မှာ သမားရိုးကျ Subject-Verb အစဉ်ကို ပြောင်းပြန်လှန်ပြီး **မေးခွန်းပုံစံကဲ့သို့ Auxiliary Verb (အရန်ကြိယာ) ကို Subject ရှေ့သို့ ပို့ကာ အလေးပေးဖော်ပြသော (Emphasis)** အဆင့်မြင့် သဒ္ဒါဖွဲ့စည်းပုံ ဖြစ်သည်:

$$\mathbf{Negative / Restrictive\ Expression} + \mathbf{Auxiliary\ Verb\ (did / does / has / should)} + \mathbf{Subject} + \mathbf{Main\ Verb}$$

| Structure | Example Sentence | အဓိပ္ပာယ်နှင့် သဒ္ဒါမှတ်ချက် |
| :--- | :--- | :--- |
| **Not only + aux + S** | *Not only did sales increase, but profits also rose.* | အရောင်းတက်ရုံသာမက အမြတ်လည်း တက်ခဲ့သည်။ |
| **Never + aux + S** | *Never have I witnessed such a remarkable result.* | ဤမျှ ထူးချွန်သော ရလဒ်မျိုးကို ကျွန်ုပ် တစ်ခါမျှ မကြုံဖူးပါ။ |
| **Rarely / Seldom** | *Rarely does the company change its policy.* | ကုမ္ပဏီသည် မူဝါဒကို ပြောင်းလဲခဲလှသည်။ |
| **Under no circumstances**| *Under no circumstances should confidential data be disclosed.* | လျှို့ဝှက်ဒေတာများကို မည်သည့်အခြေအနေတွင်မှ ပေါက်ကြားခွင့်မပြုရ။ |
| **Only after + clause** | *Only after reviewing the evidence did we understand the problem.* | သက်သေများကို ပြန်လည်စစ်ဆေးပြီးမှသာ ပြဿနာကို ကျွန်ုပ်တို့ နားလည်ခဲ့သည်။ |
| **Not until + clause** | *Not until Monday did we receive confirmation.* | တနင်္လာနေ့ရောက်မှသာ အတည်ပြုချက်ကို ကျွန်ုပ်တို့ ရရှိခဲ့သည်။ |
| **Hardly ... when** | *Hardly had we arrived when the meeting began.* | ကျွန်ုပ်တို့ ရောက်ရှိရုံ ရှိသေးသည် အစည်းအဝေး စတင်ခဲ့သည်။ |
| **No sooner ... than** | *No sooner had the announcement been made than complaints began.* | ကြေညာချက် ထုတ်ပြန်ပြီးပြီးချင်း ကန့်ကွက်မှုများ စတင်ခဲ့သည်။ |
| **Little did + S + V** | *Little did we know that the project would fail.* | ပရောဂျက် ကျရှုံးမည်ကို ကျွန်ုပ်တို့ လုံးဝ မထင်မှတ်ခဲ့ကြပါ။ |

> [!WARNING]
> **သတိပြုရန် စည်းမျဉ်း:**
> - Inversion ဖြစ်ပေါ်ရာတွင် Auxiliary Verb (do/does/did/have/should) သည် Subject ၏ ရှေ့သို့ ရောက်သွားပြီး၊ Main Verb သည် Base Form (မူရင်းကြိယာ) အဖြစ် ပြန်ပြောင်းရမည် (`did sales increase` - ❌ did sales increased မဟုတ်ပါ)။
