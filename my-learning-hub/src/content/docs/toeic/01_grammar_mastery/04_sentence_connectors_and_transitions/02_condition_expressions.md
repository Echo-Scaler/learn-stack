## Condition — အခြေအနေသတ်မှတ်ခြင်း

စီးပွားရေး စာချုပ်များ၊ စည်းကမ်းသတ်မှတ်ချက်များနှင့် ကုမ္ပဏီ မူဝါဒများတွင် မရှိမဖြစ် အသုံးများသော စကားဆက် ပုံစံများ ဖြစ်သည်:

| Expression | Grammar Pattern | Example Sentence |
| :--- | :--- | :--- |
| **If** | `If + S + V` | *If you need assistance, contact us.* |
| **Unless** | `Unless + S + V (= if not)` | *Unless you register, you cannot attend.* |
| **Provided that** | `Provided that + S + V` | *You may enter provided that you have a ticket.* |
| **Providing that** | `Providing that + S + V` | *We will proceed providing that approval is granted.* |
| **As long as** | `As long as + S + V` | *You may work remotely as long as your tasks are complete.* |
| **On condition that**| `On condition that + S + V` | *The offer is valid on condition that payment is received.* |
| **In case** | `In case + S + V` | *Save a copy in case the computer crashes.* |
| **Even if** | `Even if + S + V` | *Even if it rains, the event will continue.* |
| **Only if** | `Only if + S + V` | *You can receive a refund only if you provide a receipt.* |

> [!TIP]
> **Unless ၏ အငြင်းသဘော:** `Unless` ထဲတွင် `not` အဓိပ္ပာယ် ပါပြီးသား ဖြစ်သောကြောင့် Clause ထဲတွင် နောက်ထပ် `not` ထပ်မံ ထည့်စရာ မလိုပါ။
