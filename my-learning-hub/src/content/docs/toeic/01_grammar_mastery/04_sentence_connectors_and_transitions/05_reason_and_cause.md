## Reason and Cause — အကြောင်းရင်းပြခြင်း

အကြောင်းရင်းနှင့် အကျိုးရလဒ် (Cause and Effect) ကို ဖော်ပြသော အရေးကြီးဆုံး စကားဆက်များ ဖြစ်သည်:

| Expression | Grammar Pattern | Example Sentence |
| :--- | :--- | :--- |
| **Because** | `Because + S + V` | *Because demand increased, sales rose.* |
| **Since** | `Since + S + V` | *Since the manager was absent, we postponed the meeting.* |
| **As** | `As + S + V` | *As the office was closed, we worked remotely.* |
| **Because of** | `Because of + noun` | *The flight was delayed because of fog.* |
| **Due to** | `Due to + noun` | *The event was canceled due to rain.* |
| **Owing to** | `Owing to + noun` | *Owing to technical issues, the website was unavailable.* |
| **Thanks to** | `Thanks to + noun` (အကောင်းဘက်ရလဒ်) | *Thanks to your help, we finished early.* |
| **On account of** | `On account of + noun` | *The meeting was postponed on account of illness.* |
| **Given that** | `Given that + S + V` | *Given that demand is rising, we should increase production.* |
| **Now that** | `Now that + S + V` (လက်ရှိအခြေအနေကြောင့်) | *Now that the project is complete, we can relax.* |

> [!IMPORTANT]
> **ရွှေစည်းမျဉ်း ခွဲခြားနည်း:**
> - `Because, Since, As, Given that, Now that` -> **Clause (S + V)** လိုက်ရမည်။
> - `Because of, Due to, Owing to, Thanks to, On account of` -> **Noun / Noun Phrase** သာ လိုက်ရမည်။
