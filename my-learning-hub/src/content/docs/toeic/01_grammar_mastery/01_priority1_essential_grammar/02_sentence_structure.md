## ၁။ အင်္ဂလိပ်ဝါကျ ဖွဲ့စည်းပုံ အခြေခံ ၅ မျိုး

TOEIC Part 5 & 6 တွင် ဝါကျတစ်ခု၏ **Subject (ကတ္တား)** နှင့် **Main Verb (အဓိကကြိယာ)** ကို အလျင်အမြန် ရှာဖွေနိုင်ခြင်းသည် အမှတ်ကောင်းရန် အဓိကသော့ချက် ဖြစ်သည်။

```
Pattern 1: S + V            (The train arrived.)
Pattern 2: S + V + C        (The proposal seems realistic.)
Pattern 3: S + V + O        (The company launched a new product.)
Pattern 4: S + V + I.O + D.O(The director gave employees a bonus.)
Pattern 5: S + V + O + C    (The board considered the plan feasible.)
```

---

## ၂။ TOEIC မေးခွန်းများတွင် အထူးသတိပြုရမည့် 5th Pattern (SVOC)

TOEIC စာမေးပွဲတွင် Object Complement နေရာ၌ **Adjective** လိုက်သော ကြိယာများကို မကြာခဏ မေးလေ့ရှိသည်:
- **make / keep / find / consider / leave + Object + [ ADJECTIVE ]**
  - *We must keep customer records [ **confidential** ].* (confidentiality သို့မဟုတ် confidentially မဟုတ်ပါ)
  - *The CEO found the technical report very [ **informative** ].*

---

## ၃။ Modifier Elimination Technique (ဖြတ်ထုတ်နည်းစနစ်)

ရှည်လျားသော ဝါကျများတွင် Prepositional Phrases (ဝိဘတ်စကားစု) များကို မျက်စိထဲမှ ယာယီ ဖယ်ရှားလိုက်ပါ:
> *The shipment **[ of high-precision components from Germany ]** [ **has arrived** ] at the warehouse.*
> -> အမှန်တကယ် Subject သည် `shipment` (Singular) သာဖြစ်သဖြင့် Singular Verb `has arrived` ကို ရွေးရမည်။
