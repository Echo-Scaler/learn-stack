## ၁။ Adjective vs Adverb အခြေခံ နေရာယူမှု

- **Adjective:** Noun ကို အထူးပြုသည် (`a reliable supplier`) သို့မဟုတ် Linking Verb နောက်တွင် လိုက်သည် (`The report is accurate`).
- **Adverb:** Verb, Adjective, အခြား Adverb သို့မဟုတ် ဝါကျတစ်ခုလုံးကို အထူးပြုသည် (`The system runs smoothly`).

---

## ၂။ အထူးသတိပြုရမည့် အဓိပ္ပာယ်ပြောင်း Adverbs (Confusing Pairs)

| စကားလုံးတွဲ | ပထမစကားလုံး (Adjective / Adverb) | ဒုတိယစကားလုံး (Adverb with -ly) |
| :--- | :--- | :--- |
| **hard / hardly** | **hard** (ကြိုးစား၍ / ခဲယဉ်းသော) | **hardly** (မရှိသလောက် / ခဲယဉ်းစွာ - အငြင်းသဘော) |
| **late / lately** | **late** (နောက်ကျသော / နောက်ကျစွာ) | **lately** (မကြာသေးမီက - recently) |
| **near / nearly** | **near** (နီးကပ်သော) | **nearly** (နီးပါးခန့် - almost) |
| **high / highly** | **high** (မြင့်မားသော) | **highly** (အလွန်တရာ - highly recommended) |
| **close / closely** | **close** (နီးကပ်သော) | **closely** (အနီးကပ် သေချာစွာ - monitored closely) |
