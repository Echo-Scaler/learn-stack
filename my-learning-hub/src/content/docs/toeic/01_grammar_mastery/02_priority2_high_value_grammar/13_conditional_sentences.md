## ၁။ အခြေအနေပြ ဝါကျ ၄ မျိုး (Conditionals Matrix)

| အမျိုးအစား | If Clause (အခြေအနေ) | Main Clause (ရလဒ်) | အဓိပ္ပာယ် |
| :--- | :--- | :--- | :--- |
| **Type 0 (General Truth)** | If + Present Simple | Present Simple | အမြဲမှန်သော အချက် |
| **Type 1 (Real Future)** | If + Present Simple | will / can + V1 | အနာဂတ်တွင် ဖြစ်နိုင်ခြေရှိသော အခြေအနေ |
| **Type 2 (Unreal Present)** | If + Past Simple (were) | would / could + V1 | လက်ရှိတွင် ဖြစ်နိုင်ခြေမရှိသော စိတ်ကူး |
| **Type 3 (Unreal Past)** | If + Past Perfect (had + V3) | would have + V3 | အတိတ်တွင် ဖြစ်မလာခဲ့သော နောင်တ/အခြေအနေ |

---

## ၂။ TOEIC အကြိုက်ဆုံး: Inversion of Conditionals (If ဖြုတ်နည်း)

If ကို ဖြုတ်လိုက်ပြီး ကတ္တားနှင့် အရန်ကြိယာကို နေရာပြောင်းပြန် (Inversion) ပြုလုပ်သော ပုံစံ:

### ၁။ Type 1 Inversion: Should + S + Base Verb
- *If you have any questions -> [ **Should you have** ] any questions, please ask.*

### ၂။ Type 2 Inversion: Were + S + to-V / Complement
- *If the company were to expand -> [ **Were the company to expand** ], more staff would be needed.*

### ၃။ Type 3 Inversion: Had + S + V3
- *If we had known the risk -> [ **Had we known** ] the risk, we would have revised the strategy.*
