## ၁။ Participle as Adjective (နာမဝိသေသနအဖြစ် သုံးသော နာမဝိဘတ်)

- **Present Participle (-ing - Active / Ongoing):** အဆိုပါ နာမ်သည် ပြုလုပ်နေသည် သို့မဟုတ် အကြောင်းတရား ဖြစ်စေသည်။
- **Past Participle (-ed - Passive / Completed):** အဆိုပါ နာမ်သည် အပြုခံရသည် သို့မဟုတ် ခံစားရသည်။

```
- existing customers (လက်ရှိ ရှိနေသော ဖောက်သည်များ - active)
- proposed plan (အဆိုပြုခံထားရသော အစီအစဉ် - passive)
- updated guidelines (မွမ်းမံပြီးဖြစ်သော လမ်းညွှန်ချက်များ)
- remaining balance (ကျန်ရှိနေသေးသော လက်ကျန်ငွေ)
```

---

## ၂။ ခံစားချက်ပြ Participles (Emotion Verbs)
- **-ing (အကြောင်းရင်း / အရာဝတ္ထု):** `an exciting project, a boring speech, demanding tasks`
- **-ed (ခံစားရသူ / လူ):** `excited investors, bored audience, satisfied clients`
