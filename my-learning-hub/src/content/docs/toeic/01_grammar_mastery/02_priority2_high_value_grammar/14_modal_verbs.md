## ၁။ Core Modal Verbs
- **Must / Have to:** မဖြစ်မနေ လုပ်ဆောင်ရမည့် တာဝန် (`All visitors must wear badges.`)
- **Should / Ought to:** အကြံပြုချက် (`You should double-check the figures.`)
- **May / Might / Could:** ဖြစ်နိုင်ခြေ ခန့်မှန်းချက် (`The shipment may be delayed.`)
- **Will / Would:** အနာဂတ် ရည်ရွယ်ချက် / ယဉ်ကျေးစွာ တောင်းဆိုချက် (`Would you mind signing here?`)

## ၂။ Modal + have + V3 (Past Deduction & Regret)

| ပုံသေနည်း | အဓိပ္ပာယ် | နမူနာ ဝါကျ |
| :--- | :--- | :--- |
| **should have + V3** | လုပ်ခဲ့သင့်သော်လည်း မလုပ်ခဲ့မိ (နောင်တ) | *We [ **should have ordered** ] more supplies.* |
| **must have + V3** | ဖြစ်ခဲ့သည်မှာ သေချာသလောက်ရှိ (သေချာသော အတိတ်ခန့်မှန်းချက်) | *The flight [ **must have landed** ] by now.* |
| **could have + V3** | လုပ်နိုင်ခဲ့သော်လည်း မလုပ်ဖြစ်ခဲ့ | *They [ **could have completed** ] it earlier.* |
| **cannot have + V3** | ဖြစ်နိုင်ခြေ လုံးဝမရှိခဲ့ | *He [ **cannot have known** ] the secret.* |
