## Paraphrase Mastery List (TOEIC စကားလုံးအလှည့်အပြောင်း လျှို့ဝှက်ချက်များ)
## (Part 3, 4, 7 တွင် အဖြေမှန်ကို ချက်ချင်းရှာဖွေနိုင်သော 言い換え (Iikae) ပုံစံများ)

TOEIC စာမေးပွဲတွင် ၆၀၀ မှတ် ရရှိသူနှင့် **၈၀၀+ မှတ် ရရှိသူတို့၏ အကြီးမားဆုံး ခြားနားချက်မှာ "Paraphrasing (စကားလုံး အလှည့်အပြောင်း)" ကို ရိပ်မိခြင်း** ဖြစ်ပါသည်။ 

စာပိုဒ် (Passage) သို့မဟုတ် အသံဖိုင် (Audio) ထဲတွင် ပါဝင်သော မူရင်းစကားလုံးသည် မေးခွန်း၏ အဖြေမှန် (Correct Option) တွင် တိုက်ရိုက်ပါခဲပြီး၊ **အဓိပ္ပာယ်တူ အခြားစကားလုံး သို့မဟုတ် ခြုံငုံသုံးစကားလုံး (Broader Term)** ဖြင့် အမြဲ ပြောင်းလဲထားလေ့ရှိပါသည်။

---

### ၁။ လုပ်ငန်းဆောင်ရွက်မှုဆိုင်ရာ အလှည့်အပြောင်းများ (Corporate Actions)

| မူရင်း စာပိုဒ်/အသံဖိုင်ထဲမှ စကားလုံး (Original Text) | မေးခွန်းအဖြေလွှာထဲမှ ပြောင်းလဲချက် (Paraphrased Answer) | မြန်မာလို အဓိပ္ပာယ် |
| :--- | :--- | :--- |
| **renovate the office** | **make improvements to a facility** | ရုံးခန်းကို အဆင့်မြှင့်တင် ပြင်ဆင်သည် |
| **call off the meeting** | **cancel an event** | အစည်းအဝေးကို ဖျက်သိမ်းသည် |
| **submit a résumé** | **apply for a position / job** | အလုပ်လျှောက်လွှာ တင်သွင်းသည် |
| **give a talk / speech** | **deliver a presentation** | ဟောပြောပို့ချချက် ပေးသည် |
| **hire additional staff** | **expand the workforce / recruit personnel** | ဝန်ထမ်းအင်အား ထပ်မံဖြည့်တင်းသည် |
| **inspect the equipment** | **examine machinery** | စက်ပစ္စည်းများကို စစ်ဆေးသည် |
| **buy / purchase components** | **procure / acquire materials** | ပစ္စည်းကိရိယာများကို ဝယ်ယူစုဆောင်းသည် |
| **launch a new product** | **introduce an item to the market** | ကုန်ပစ္စည်းအသစ်ကို စတင်မိတ်ဆက်သည် |
| **set up a meeting** | **schedule an appointment / arrange a discussion** | အစည်းအဝေးတစ်ခု စီစဉ်သတ်မှတ်သည် |
| **take inventory** | **check stock levels** | လက်ကျန်စာရင်း စစ်ဆေးသည် |

---

### ၂။ ဘဏ္ဍာရေးနှင့် ဈေးနှုန်းဆိုင်ရာ အလှည့်အပြောင်းများ (Finance & Pricing)

| Original Text | Paraphrased Answer | မြန်မာလို အဓိပ္ပာယ် |
| :--- | :--- | :--- |
| **discount / 20% off** | **reduced rate / special promotional offer** | လျှော့ဈေး / အထူးနှုန်းထား |
| **reimburse travel expenses** | **compensate for business costs** | ခရီးစရိတ်များ ပြန်လည်ထုတ်ပေးသည် |
| **cost-effective** | **economical / budget-friendly** | ကုန်ကျစရိတ် သက်သာသော |
| **exceed the budget** | **surpass financial limits** | သတ်မှတ်ဘတ်ဂျက်ထက် ကျော်လွန်သည် |
| **free of charge** | **complimentary / at no extra cost** | အခမဲ့ ဝန်ဆောင်မှု |
| **raise prices** | **implement a rate increase** | ဈေးနှုန်းများ တိုးမြှင့်သည် |

---

### ၃။ ဆက်သွယ်ရေးနှင့် အချိန်ဇယားဆိုင်ရာ အလှည့်အပြောင်းများ (Communication & Time)

| Original Text | Paraphrased Answer | မြန်မာလို အဓိပ္ပာယ် |
| :--- | :--- | :--- |
| **delay / take longer than planned** | **postpone / experience a setback** | အချိန်ကြန့်ကြာသည် / ရွှေ့ဆိုင်းသည် |
| **contact / call Mr. Davis** | **get in touch with / reach out to a colleague** | လုပ်ဖော်ကိုင်ဖက်ထံ ဆက်သွယ်သည် |
| **right away / immediately** | **promptly / without delay** | ချက်ချင်းမဆိုင်း |
| **brochure / flyer / leaflet** | **promotional material / informational pamphlet** | ကြော်ငြာစာရွက်စာတမ်း |
| **annual meeting** | **yearly gathering / once-a-year conference** | နှစ်ပတ်လည် အစည်းအဝေး |

---

### ၄။ ပစ္စည်းနှင့် နေရာအမည်များကို ခြုံငုံသုံးစကားလုံးဖြင့် ပြောင်းလဲခြင်း (Category Generalization)

TOEIC တွင် သီးသန့်ပစ္စည်းအမည် (Specific Item) ကို ခြုံငုံသော အမည် (Category Noun) ဖြင့် အလှည့်အပြောင်း ပြုလုပ်လေ့ရှိပါသည်:

| မူရင်းဖော်ပြချက် (Specific Items) | အဖြေလွှာတွင် ပြောင်းလဲသောအမည် (General Category) |
| :--- | :--- |
| *hotel, inn, resort, motel* | $\rightarrow$ **accommodations / lodging** (တည်းခိုနေထိုင်ရာ နေရာ) |
| *car, bus, train, ferry* | $\rightarrow$ **transportation / vehicle** (သယ်ယူပို့ဆောင်ရေး ယာဉ်) |
| *laptop, printer, monitor, tablet* | $\rightarrow$ **electronic equipment / office devices** (ရုံးသုံး အီလက်ထရွန်းနစ် စက်ကိရိယာ) |
| *hammer, wrench, drill, saw* | $\rightarrow$ **tools / instruments** (လက်သမားသုံး ကိရိယာတန်ဆာပလာများ) |
| *shirts, pants, jackets, dresses* | $\rightarrow$ **apparel / garments / attire** (အဝတ်အထည်များ) |
| *apples, milk, bread, cheese* | $\rightarrow$ **groceries / foodstuffs** (ကုန်စုံ စားသောက်ကုန်များ) |

---

### ၅။ Paraphrasing ကို အသုံးချ၍ အဖြေရှာသည့် နမူနာ (Practical Example)

#### မေးခွန်း:
> **What does the man offer to do?**  
> (A) Repair an electronic device  
> (B) Deliver some merchandise  
> (C) Purchase office furniture  
> (D) Schedule a medical appointment  

#### မူရင်း စကားပြောခန်း (Audio Script):
> *"Don't worry, Ms. Green. I will take a look at your malfunctioning laptop and see if I can fix the hard drive."*

**မြန်မာလို သုံးသပ်ချက်**:
- Audio တွင် `fix your malfunctioning laptop` ဟု ပြောခဲ့သော်လည်း Option တွင် ထိုစကားလုံး မပါရှိပါ။
- `fix` ကို `Repair` ဟု လည်းကောင်း၊ `laptop` ကို `an electronic device` ဟု လည်းကောင်း Paraphrase ပြုလုပ်ထားသောကြောင့် (A) **Repair an electronic device** သည် အဖြေမှန် ဖြစ်ပါသည်။
