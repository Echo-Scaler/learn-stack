# Feature 12: Amazon S3 Glacier ကို မြန်မာလို အခြေခံမှ လက်တွေ့အထိ
### Ultra Low-Cost Storage Class for Data Archiving and Long-Term Backup & SAA-C03 Guide

**Amazon S3 Glacier** သည် ရေရှည် မော်ကွန်းသိမ်းဆည်းမှု (Data Archiving) နှင့် ဘေးအန္တရာယ် ကာကွယ်ရေး အရန်သိမ်းဆည်းမှု (Long-term Disaster Recovery Backup) များအတွက် ကမ္ဘာ့ကုန်ကျစရိတ် အသက်သာဆုံးသော **Cold Storage Service** ဖြစ်ပါသည်။ 99.999999999% (11 9s) Durability အပြည့်အဝ ပေးစွမ်းပြီး ငွေကြေးဆိုင်ရာ၊ ကျန်းမာရေးဆိုင်ရာ ဥပဒေစည်းမျဉ်း (WORM Regulatory Compliance) လိုအပ်ချက်များအတွက် မရှိမဖြစ် အသုံးပြုရပါသည်။
