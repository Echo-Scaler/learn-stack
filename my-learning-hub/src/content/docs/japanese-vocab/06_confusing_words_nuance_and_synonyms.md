# JLPT N1 Essential Vocabulary: စကားလုံးအတွဲများ၏ သိမ်မွေ့သော သုံးစွဲပုံ ကွဲပြားချက်များ (類義語・使い分け)

JLPT N1 စာမေးပွဲ၏ **問題 4: 用法 (Correct Word Usage)** တွင် မေးခွန်းထုတ်လေ့ရှိသော အဓိက ထောင်ချောက်မှာ "အဘိဓာန် အဓိပ္ပာယ် ဆင်တူသော်လည်း လက်တွေ့တွင် မည်သည့် context နှင့် မည်သည့် collocation ဖြင့်သာ သုံးရမည်ကို သိ/မသိ" စစ်ဆေးခြင်း ဖြစ်ပါသည်။ ဤအခန်းတွင် N1 စာမေးပွဲ၌ အမှားအများဆုံး စကားလုံးအတွဲများကို အသေးစိတ် နှိုင်းယှဉ်ရှင်းလင်းထားပါသည်။

## ၁။ 執着 (しゅうちゃく / shūchaku) vs 固執 (こしつ / koshitsu)

| စကားလုံး (Word) | Romaji | ပင်မ သဘောသဘာဝ (Core Concept) | အဓိက တွဲစပ်မှု (Collocations) |
| :--- | :--- | :--- | :--- |
| **執着** *(shūchaku)* | *shūchaku* | **စိတ်ပိုင်းဆိုင်ရာ စွဲလမ်းမှု** (မစွန့်လွှတ်နိုင်ဘဲ တမ်းတတွယ်တာနေခြင်း) | 過去への執着 / 金銭への執着 / 執着心 |
| **固執** *(koshitsu)* | *koshitsu* | **မိမိ၏ သဘောထား၊ စည်းမျဉ်းကို အလျှော့မပေးဘဲ တင်းခံခေါင်းမာနေခြင်း** | 自分の意見に固執する / 従来の方法に固執する |

### 📝 နမူနာဝါကျ နှိုင်းယှဉ်ချက်
- **執着**: 彼は過去の栄光にいつまでも**執着**している。
  - *Kare wa kako no eikō ni itsumademo **shūchaku** shite iru.*
  - (သူသည် အတိတ်က ရရှိခဲ့ဖူးသော အောင်မြင်မှုဂုဏ်ရည်ကို ယနေ့တိုင် မစွန့်လွှတ်နိုင်ဘဲ **တမ်းတစွဲလမ်းနေဆဲ** ဖြစ်သည်။)
- **固執**: 周囲の反対を無視して、自分のやり方に**固執**するのは賢明ではない。
  - *Shūi no hantai o mushi shite, jibun no yarikata ni **koshitsu** suru no wa kenmei de wa nai.*
  - (ပတ်ဝန်းကျင်၏ ကန့်ကွက်မှုကို လျစ်လျူရှုကာ မိမိ၏ လုပ်နည်းလုပ်ဟန်အပေါ်တွင်သာ **ခေါင်းမာတင်းခံနေခြင်း** မှာ ပညာရှိသော လုပ်ရပ် မဟုတ်ပေ။)

## ၂။ 是正 (ぜせい / zesei) vs 改善 (かいぜん / kaizen)

| စကားလုံး (Word) | Romaji | ပင်မ သဘောသဘာဝ (Core Concept) | အဓိက တွဲစပ်မှု (Collocations) |
| :--- | :--- | :--- | :--- |
| **是正** *(zesei)* | *zesei* | **မမှန်ကန်သော အခြေအနေ၊ မတရားမှု၊ အကျင့်ဆိုး သို့မဟုတ် ကွာဟချက်ကို တည့်မတ်ဖြောင့်တန်းစေခြင်း** | 格差を是正する / 不公平を是正する / 欠陥の是正 |
| **改善** *(kaizen)* | *kaizen* | **လက်ရှိ အခြေအနေကို ယခင်ထက် ပိုမိုကောင်းမွန် အရည်အသွေးမြင့်မားအောင် ပြုပြင်ခြင်း** | 待遇を改善する / 業務効率を改善する / 体質改善 |

### 📝 နမူနာဝါကျ နှိုင်းယှဉ်ချက်
- **是正**: 男女間の賃金格差を**是正**するための法整備が進められている。
  - *Danjo-kan no chingin kakusa o **zesei** suru tame no hōseibi ga susumerarete iru.*
  - (ကျား/မ အကြား လုပ်ခလစာ မညီမျှသော ကွာဟချက်ကို **တည့်မတ်ဖြောင့်တန်းစေရန်** ဥပဒေ ပြင်ဆင်မှုများ ဆောင်ရွက်လျက်ရှိသည်။)
- **改善**: 新しいシステムの導入により、作業効率が大幅に**改善**された。
  - *Atarashii shisutemu no dōnyū ni yori, sagyō kōritsu ga ōhaba ni **kaizen** sareta.*
  - (စနစ်အသစ် ထည့်သွင်းအသုံးပြုမှုကြောင့် လုပ်ငန်းလည်ပတ်မှု စွမ်းဆောင်ရည်မှာ သိသိသာသာ **ပိုမိုတိုးတက်ကောင်းမွန်လာခဲ့သည်**။)

## ၃။ 懸念 (けねん / kenen) vs 不安 (ふあん / fuan)

| စကားလုံး (Word) | Romaji | ပင်မ သဘောသဘာဝ (Core Concept) | အဓိက တွဲစပ်မှု (Collocations) |
| :--- | :--- | :--- | :--- |
| **懸念** *(kenen)* | *kenen* | **အနာဂတ် ဆိုးကျိုးသက်ရောက်မှုအပေါ် နိုင်ငံရေး၊ စီးပွားရေး သို့မဟုတ် ပညာရပ်ဆိုင်ရာ ရှုထောင့်မှ တရားဝင် စိုးရိမ်ပူပန်မှု (Formal/Written)** | 景気後退が懸念される / 影響を懸念する / 懸念材料 |
| **不安** *(fuan)* | *fuan* | **လူတစ်ဦးချင်းစီ၏ စိတ်ပိုင်းဆိုင်ရာ မလုံခြုံမှု၊ သာမန် စိုးရိမ်ကြောင့်ကြမှု (Personal Emotion)** | 一人暮らしで不安だ / 将来への不安 |

### 📝 နမူနာဝါကျ နှိုင်းယှဉ်ချက်
- **懸念**: 円安の長期化が、日本経済の先行きに及ぼす影響が**懸念**されている。
  - *En'yasu no chōkika ga, Nihon keizai no sakiyuki ni oyobosu eikyō ga **kenen** sarete iru.*
  - (ယန်းငွေတန်ဖိုး ကျဆင်းမှု ရှည်ကြာလာခြင်းက ဂျပန်စီးပွားရေး အနာဂတ်အပေါ် သက်ရောက်မည့် အကျိုးဆက်များကို **စိုးရိမ်ပူပန်လျက်ရှိကြသည်**။)
- **不安**: 初めての海外旅行なので、少し**不安**を感じている。
  - *Hajimete no kaigai ryokō na node, sukoshi **fuan** o kanjite iru.*
  - (ပထမဆုံးအကြိမ် ပြည်ပခရီးသွားခြင်းဖြစ်၍ အနည်းငယ် **စိတ်မလုံခြုံ စိုးရိမ်ကြောင့်ကြမှု** ဖြစ်ပေါ်နေသည်။)

## ၄။ 措置 (そち / sochi) vs 対策 (たいさく / taisaku)

| စကားလုံး (Word) | Romaji | ပင်မ သဘောသဘာဝ (Core Concept) | အဓိက တွဲစပ်မှု (Collocations) |
| :--- | :--- | :--- | :--- |
| **措置** *(sochi)* | *sochi* | **အာဏာပိုင် သို့မဟုတ် စီမံခန့်ခွဲသူများက တရားဝင် ချမှတ်အကောင်အထည်ဖော်သော သီးသန့် အရေးယူဆောင်ရွက်ချက်** | 緊急措置を講じる / 適切な措置をとる / 法的措置 |
| **対策** *(taisaku)* | *taisaku* | **ပြဿနာ သို့မဟုတ် အန္တရာယ်တစ်ခုခုကို ရင်ဆိုင်ဖြေရှင်းရန် ကြိုတင်ပြင်ဆင်သော နည်းဗျူဟာနှင့် မဟာဗျူဟာများ** | 寒さ対策 / 地震対策を立てる / 試験対策 |

### 📝 နမူနာဝါကျ နှိုင်းယှဉ်ချက်
- **措置**: 違法行為に対しては、法に基づく厳格な**措置**を講じる方針だ。
  - *Ihitakōi ni taishi wa, hō ni motozuku genkaku na **sochi** o kōjiru hōshin da.*
  - (တရားမဝင် လုပ်ရပ်များအပေါ် ဥပဒေနှင့်အညီ တင်းကျပ်သော **အရေးယူဆောင်ရွက်မှု** များ ချမှတ်မည့် မူဝါဒ ဖြစ်သည်။)
- **対策**: 今後の異常気象に備えて、万全の防災**対策**を練る必要がある。
  - *Kongo no ijō kishō ni sonaete, banzen no bōsai **taisaku** o neru hitsuyō ga aru.*
  - (နောင်လာမည့် ပြင်းထန်သော ရာသီဥတုဆိုးများအတွက် အပြည့်အဝ ကြိုတင်ကာကွယ်ရေး **နည်းဗျူဟာမဟာဗျူဟာများ** ရေးဆွဲထားရန် လိုအပ်သည်။)

## ၅။ 怠る (おこたる / okotaru) vs 怠ける (なまける / namakeru)

| စကားလုံး (Word) | Romaji | ပင်မ သဘောသဘာဝ (Core Concept) | အဓိက တွဲစပ်မှု (Collocations) |
| :--- | :--- | :--- | :--- |
| **怠る** *(okotaru)* | *okotaru* | **မဖြစ်မနေ လုပ်ဆောင်ရမည့် တာဝန်၊ ကြိုတင်ပြင်ဆင်မှု သို့မဟုတ် ဂရုစိုက်မှုကို ပေါ့ဆ၍ ပျက်ကွက်သည်** | 準備を怠る / 警戒を怠る / 報告を怠る |
| **怠ける** *(namakeru)* | *namakeru* | **ပျင်းရိသဖြင့် အလုပ်မလုပ်ဘဲ အချိန်ဖြုန်းနေသည် (Lazy)** | 仕事を怠ける / 勉強を怠けて遊ぶ |

### 📝 နမူနာဝါကျ နှိုင်းယှဉ်ချက်
- **怠る**: 日常の点検を**怠った**ことが、大事故につながった。
  - *Nichijō no tenken o **okotatta** koto ga, daijiko ni tsunagatta.*
  - (နေ့စဉ် စစ်ဆေးမှုကို **ပေါ့ဆပျက်ကွက်ခဲ့ခြင်း** က ကြီးမားသော ယာဉ်မတော်တဆမှုဆီသို့ ဦးတည်သွားစေခဲ့သည်။)
- **怠ける**: 彼は仕事を**怠けて**、一日中スマートフォンをいじっていた。
  - *Kare wa shigoto o **namakete**, ichinichijū sumātofon o ijitte ita.*
  - (သူသည် အလုပ်ကို **ပျင်းရိ၍ မလုပ်ဘဲ** တစ်နေကုန် စမတ်ဖုန်းကိုသာ ကလိနေခဲ့သည်။)

## ၆။ 促す (うながす / unagasu) vs 勧める (すすめる / susumeru)

| စကားလုံး (Word) | Romaji | ပင်မ သဘောသဘာဝ (Core Concept) | အဓိက တွဲစပ်မှု (Collocations) |
| :--- | :--- | :--- | :--- |
| **促す** *(unagasu)* | *unagasu* | **နှောင့်နှေးမနေဘဲ ချက်ချင်း အကောင်အထည်ဖော်ရန် ဖိအားပေးတိုက်တွန်းသည် / အရှိန်မြှင့်တင်သည်** | 注意を促す / 早期の決断を促す / 成長を促す |
| **勧める** *(susumeru)* | *susumeru* | **ကောင်းမွန်သောအရာကို အခြားသူအား စေတနာဖြင့် အကြံပြုတိုက်တွန်းသည် (Recommend)** | 読書を勧める / 入会を勧める |

### 📝 နမူနာဝါကျ နှိုင်းယှဉ်ချက်
- **促す**: 締め切りが迫っているため、担当者に提出を**促した**。
  - *Shimekiri ga sematte iru tame, tantōsha ni teishutsu o **unagashita**.*
  - (သတ်မှတ်ရက် နီးကပ်လာပြီဖြစ်သဖြင့် တာဝန်ခံအား အမြန်တင်ပြရန် **အရှိန်မြှင့်တိုက်တွန်းနှိုးဆော်ခဲ့သည်**။)
- **勧める**: 先生は私に、海外留学を強く**勧めて**くださった。
  - *Sensei wa watashi ni, kaigai ryūgaku o tsuyoku **susumete** kudasatta.*
  - (ဆရာသည် ကျွန်တော့်အား ပြည်ပပညာသင်သွားရန် အလေးအနက် **အကြံပြုတိုက်တွန်းခဲ့သည်**။)

## ၇။ 覆す (くつがえす / kutsugaesu) vs ひっくり返す (ひっくりかえす / hikkurikaesu)
- **覆す**: တရားရုံးစီရင်ချက်၊ သာမန်အသိ (常識) သို့မဟုတ် ရာဇပလ္လင် အစိုးရအဖွဲ့ကို **တရားဝင် သို့မဟုတ် သဘောတရားအရ ပြောင်းပြန်လှန်ပစ်သည်** (判決を覆す / 常識を覆す)။
- **ひっくり返す**: ခွက်မှောက်ခြင်း၊ ပစ္စည်းပြုတ်ကျခြင်း စသော **ရုပ်ဝတ္ထုပစ္စည်းကို ဇောက်ထိုး လှန်ပစ်ခြင်း** (コップをひっくり返す)။

## ၈။ 卓越 (たくえつ / takuetsu) vs 優秀 (ゆうしゅう / yūshū)
- **卓越**: အခြားသူများနှင့် နှိုင်းယှဉ်၍ မရလောက်အောင် **ထူးခြားပြောင်မြောက်စွာ သာလွန်ထိုးထွက်နေသော စွမ်းရည်** (卓越した技術 / 卓越した才能)။
- **優秀**: စံနှုန်းတစ်ခု သတ်မှတ်ချက်အတွင်း အဆင့်မြင့်မားသော **ရလဒ်ကောင်း၊ အမှတ်ကောင်း ထူးချွန်မှု** (優秀な成績 / 優秀な社員)။

## ၉။ 契機 (けいき / keiki) vs きっかけ (kikkake)
- **契機**: သမိုင်းဝင်ဖြစ်ရပ်၊ ကုမ္ပဏီအပြောင်းအလဲကြီးများအတွက်သုံးသော **တရားဝင် စာပေသုံး အလှည့်အပြောင်း ခြေလှမ်း** (これを契機として / 発展の契機)။
- **きっかけ**: နေ့စဉ် စကားပြောတွင်သုံးသော **သာမန် စတင်ဖြစ်ပေါ်စေသည့် အကြောင်းရင်း** (日本に来たきっかけ / 好きになったきっかけ)။

## ၁၀။ 把握 (はあく / haaku) vs 理解 (りかい / rikai)
- **把握**: လက်ရှိအခြေအနေ၊ ကိန်းဂဏန်းနှင့် ပြဿနာ၏ သဘောသဘာဝကို **လက်ဆုပ်လက်ကိုင် တိကျစွာ သဘောပေါက်ထားခြင်း** (現状を把握する)။
- **理解**: အကြောင်းအရာ၏ အဓိပ္ပာယ် သို့မဟုတ် သူတစ်ပါး၏ စိတ်ခံစားချက်ကို **စာနာနားလည်ပေးခြင်း** (気持ちを理解する / 意味を理解する)။

## ၁၁။ 収束 (しゅうそく / shūsoku) vs 終息 (しゅうそく / shūsoku)
- **収束**: ကပ်ရောဂါ၊ အဓိကရုဏ်း သို့မဟုတ် ပြဿနာသည် လုံးဝမပြီးဆုံးသေးသော်လည်း **တဖြည်းဖြည်း ငြိမ်သက်ထိန်းချုပ်နိုင်သော အခြေအနေသို့ ရောက်ရှိခြင်း** (事態が収束に向かう)။
- **終息**: ရောဂါ သို့မဟုတ် စစ်ပွဲသည် **လုံးဝအပြီးတိုင် ချုပ်ငြိမ်း ပျောက်ကွယ်သွားခြင်း** (戦争が終息する / 完全終息)။

## ၁၂။ 示唆 (しさ / shisa) vs 暗示 (あんじ / anji)
- **示唆**: အချက်အလက်၊ သုတေသနက ဖြေရှင်းနည်းလမ်းကို **အရိပ်အမြွက် ညွှန်ပြအကြံပြုခြင်း** (ヒントを示唆する / 今後の動向を示唆する)။
- **暗示**: စိတ်ပညာအရ စိတ်အာရုံသွင်းခြင်း သို့မဟုတ် လျှို့ဝှက်စွာ အရိပ်အယောင်ပြခြင်း (自己暗示 / 不吉な予兆を暗示する)။

## ၁၃။ 是認 (ぜにん / zenin) vs 承認 (しょうにん / shōnin)
- **是認**: ဖြစ်ပျက်နေသော အခြေအနေကို မှန်ကန်သင့်တော်သည်ဟု **လက်ခံအသိအမှတ်ပြုခြင်း** (現状を是認する)။
- **承認**: စီမံကိန်း သို့မဟုတ် တောင်းဆိုချက်ကို အထက်လူကြီးက **တရားဝင် ခွင့်ပြုအတည်ပြုပေးခြင်း** (計画を承認する / 申請の承認)။

## ၁၄။ 拘束 (こうそく / kōsoku) vs 制限 (せいげん / seigen)
- **拘束**: လူ၏ လွတ်လပ်ခွင့် သို့မဟုတ် အချိန်ကို **ချုပ်ချယ်ချည်နှောင်ထားခြင်း** (身柄を拘束する / 時間の拘束)။
- **制限**: ပမာဏ၊ အမြန်နှုန်း သို့မဟုတ် အရေအတွက်ကို **ကန့်သတ်ဘောင်ခတ်ထားခြင်း** (速度制限 / 人数制限)။

## ၁၅။ 妥協 (だきょう / dakyō) vs 譲歩 (じょうほ / jōho)
- **妥協**: နှစ်ဖက်စလုံးက အပြန်အလှန် လျှော့ပေးကာ **အလယ်အလတ် သဘောတူညီချက် ရယူခြင်း** (双方の妥協点)။
- **譲歩**: မိမိဘက်မှ အခွင့်အရေးတစ်ခုကို တစ်ဖက်လူအတွက် **တစ်ဖက်သတ် အလျှော့ပေးလိုက်လျောခြင်း** (相手に譲歩する)။

## ၁၆။ 巧妙 (こうみょう / kōmyō) vs 器用 (きよう / kiyou)
- **巧妙**: လှည့်ကွက်၊ အစီအစဉ် သို့မဟုတ် အကြံအစည် **ပါးနပ်လိမ္မာလွန်းခြင်း** (巧妙な罠 / 巧妙な手口)။
- **器用**: လက်မှုပညာ သို့မဟုတ် ကိုယ်လက်လှုပ်ရှားမှု **သွက်လက်ကျွမ်းကျင်ခြင်း** (手先が器用だ / 要領よく生きる器用さ)။

## ၁၇။ 歴然 (れきぜん / rekizen) vs 明白 (めいはく / meihaku)
- **歴然**: နှိုင်းယှဉ်ချက်အရ ကွာဟချက်သည် **မျက်ဝါးထင်ထင် ထင်ရှားစွာ ပေါ်လွင်နေခြင်း** (実力の差は歴然だ)။
- **明白**: သံသယဖြစ်စရာမရှိဘဲ **သေချာရှင်းလင်းပြတ်သားနေသော အမှန်တရား** (明白な証拠 / 明白な事実)။

## ၁၈။ 露骨 (ろこつ / rokotsu) vs 露見 (ろけん / roken)
- **露骨**: မနှစ်သက်မှု သို့မဟုတ် ရည်ရွယ်ချက်ကို **ဗြောင်ကျကျ ဖုံးကွယ်မထားဘဲ ပြသခြင်း** (露骨に嫌な顔をする / 露骨な敵意)။
- **露見**: ဖုံးကွယ်ထားသော မကောင်းမှု၊ လျှို့ဝှက်ချက် **လူမိ၍ ဘူးပေါ်သလို ပေါ်သွားခြင်း** (悪事が露見する / 計画が露見する)။

## ၁၉။ 抑制 (よくせい / yokusei) vs 抑圧 (よくあつ / yokuatsu)
- **抑制**: စိတ်ခံစားမှု သို့မဟုတ် ငွေကြေးဖောင်းပွမှုကို **ထိန်းသိမ်းချုပ်တည်းခြင်း** (感情を抑制する / インフレの抑制)။
- **抑圧**: အာဏာ သို့မဟုတ် အင်အားသုံး၍ **ဖိနှိပ်ချုပ်ချယ်ခြင်း** (言論の抑圧 / 少数民族を抑圧する)။

## ၂၀။ 模索 (もさく / mosaku) vs 探索 (たんさく / tansaku)
- **模索**: နည်းလမ်းမရှိသေးဘဲ အမှောင်ထဲတွင် **စမ်းတဝါးဝါး ရှာဖွေခြင်း** (解決策を模索する / 新たな道を模索する)။
- **探索**: ရှိပြီးသား အချက်အလက် သို့မဟုတ် ပျောက်ဆုံးနေသောအရာကို **စနစ်တကျ လိုက်လံစုံစမ်းရှာဖွေခြင်း** (原因を探索する / 遭難者の探索)။
