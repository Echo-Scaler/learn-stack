> **Beginner မှ Job-Ready Production DevOps Engineer & SRE အဆင့်သို့ စနစ်တကျ တက်လှမ်းနိုင်မည့် လက်တွေ့အသုံးချ သင်ရိုးလမ်းညွှန် (မြန်မာဘာသာ)**

မင်္ဂလာပါ! ဤ **DevOps Engineer Master Guide** သည် Software Development သို့မဟုတ် IT အခြေခံရှိသူတစ်ဦးအား အခြေခံမှစတင်၍ လုပ်ငန်းခွင်သုံး **Production DevOps Engineer, Cloud Architect & Site Reliability Engineer (SRE)** အဆင့်အထိ စနစ်တကျ တက်လှမ်းနိုင်စေရန် ရေးဆွဲထားသော **Burmese-First (မြန်မာဘာသာ ရှင်းလင်းချက်) + English Technical Terms** ပြည့်စုံသည့် လက်တွေ့ သင်ရိုးလမ်းညွှန် ဖြစ်ပါသည်။

## 🏆 ၃။ Real-World Capstone Portfolio Projects (၄ ခု အပြည့်အစုံ)

လုပ်ငန်းခွင်သုံး Enterprise စံချိန်စံညွှန်းများနှင့် ကိုက်ညီသော Capstone Portfolio Projects ၄ ခု၏ အပြည့်အစုံ Source Code နှင့် Setup လမ်းညွှန်များ:

1. 📌 [**Project A: Linux Server Automated Health & Backup Monitor**](/devops-guide/15-projects/project-a-specs/)
   - *Tech Stack*: Bash, Linux Cron, gzip, OpenSSL AES-256, AWS S3 CLI, Telegram Webhook Bot
   - *Deliverable*: Automated MySQL dump, offsite S3 synchronization, 7-day lifecycle retention, and rich HTML Telegram failure notifications.
2. 📌 [**Project B: Production Multi-Tier Containerized Web Stack**](/devops-guide/15-projects/project-b-specs/)
   - *Tech Stack*: Docker, Docker Compose, Nginx SSL Reverse Proxy, Node.js API / PHP, PostgreSQL, Redis
   - *Deliverable*: Multi-stage Dockerfile hardening (<100MB), non-root execution (`USER appuser`), persistent named volumes, isolated bridge networks, and zero-downtime rolling updates.
3. 📌 [**Project C: Enterprise Automated CI/CD Pipeline**](/devops-guide/15-projects/project-c-specs/)
   - *Tech Stack*: GitHub Actions, Docker Buildx, Trivy Vulnerability Scanner, Gitleaks, AWS ECR/Docker Hub, SSH Remote Deploy
   - *Deliverable*: Automated lint & tests, secret leak prevention, container CVE security gates, GitHub Actions cache API, and zero-downtime SSH deploy with automated healthcheck rollback.
4. 📌 [**Project D: End-to-End AWS Production Cloud Architecture via Terraform IaC**](/devops-guide/15-projects/project-d-specs/)
   - *Tech Stack*: Terraform / OpenTofu, AWS Custom VPC, Public/Private Subnets, NAT Gateway, Application Load Balancer (ALB), EC2 Auto Scaling, RDS PostgreSQL Multi-AZ
   - *Deliverable*: Declarative IaC, remote state in S3 with DynamoDB state locking, Security Group chaining (`ALB ➜ App ➜ DB`), least-privilege IAM roles, and automated teardown scripts.
