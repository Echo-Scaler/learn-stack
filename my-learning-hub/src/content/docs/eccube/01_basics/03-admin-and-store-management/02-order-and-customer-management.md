## Module 03 - အခန်း ၂: အော်ဒါနှင့် Customer စီမံခန့်ခွဲမှု (受注・会員・店舗設定)

E-Commerce လုပ်ငန်းတစ်ခု၏ နေ့စဉ် အဓိက လည်ပတ်မှုဖြစ်သော **အော်ဒါလက်ခံခြင်း၊ အခြေအနေပြောင်းလဲခြင်း (Order Processing Workflow)**၊ **Customer စီမံခန့်ခွဲမှု (Customer Management)** နှင့် **ဆိုင်အခြေခံသတ်မှတ်ချက်များ (Store Settings)** ကို ဤအခန်းတွင် ရှင်းလင်းတင်ပြပါမည်။

---

## ၁။ အော်ဒါစီမံခန့်ခွဲမှု (Order Management - 受注管理)

Customer တစ်ဦးမှ ပစ္စည်းကို ဝယ်ယူလိုက်သည့်အခါမှစ၍ ပစ္စည်းပို့ဆောင်ပြီးစီးသည်အထိ အဆင့်ဆင့်သော လုပ်ငန်းစဉ် (Order Workflow) ကို EC-CUBE တွင် စနစ်တကျ စီမံနိုင်ပါသည်။

### အော်ဒါလုပ်ငန်းစဉ် အဆင့်ဆင့် (Order Lifecycle Flowchart):

```
       [ Customer မှ Order တင်ခြင်း ]
                      │
                      ▼
        ┌───────────────────────────┐
        │  新規受付 (New Received)    │ ── (Credit Card ဖြင့် ချက်ချင်းရှင်းပါက) ──┐
        └─────────────┬─────────────┘                                         │
                      │ (Bank Transfer / ကွန်ဗီးနီး ဖြစ်ပါက)                    │
                      ▼                                                       │
        ┌───────────────────────────┐                                         │
        │  入金待ち (Waiting Payment) │                                         │
        └─────────────┬─────────────┘                                         │
                      │ (ငွေလွှဲလက်ခံရရှိသည့်အခါ)                                  │
                      ▼                                                       │
        ┌───────────────────────────┐                                         │
        │  入金済み (Payment Done)   │ ◄───────────────────────────────────────┘
        └─────────────┬─────────────┘
                      │ (ဂိုဒေါင်မှ ပစ္စည်းထုပ်ပိုးပြင်ဆင်ခြင်း)
                      ▼
        ┌───────────────────────────┐
        │  発送準備中 (Preparing)    │
        └─────────────┬─────────────┘
                      │ (ပို့ဆောင်ရေးကုမ္ပဏီသို့ အပ်နှံပြီး Tracking No. ထည့်ခြင်း)
                      ▼
        ┌───────────────────────────┐
        │  発送済み (Shipped)        │ ──► [ Customer ထံသို့ ပို့ဆောင်ပြီး Email ပို့ခြင်း ]
        └───────────────────────────┘
```

## ၂။ EC-CUBE ရှိ အဓိက Order Status များ (注文ステータス)

| Status Name (ဂျပန်) | အဓိပ္ပာယ် (English / မြန်မာ) | ရှင်းလင်းချက် |
| :--- | :--- | :--- |
| **新規受付** | New Order / အော်ဒါအသစ် | Customer မှ အော်ဒါတင်လိုက်သော မူလအခြေအနေ။ |
| **入金待ち** | Waiting for Payment / ငွေလွှဲစောင့်ဆိုင်းဆဲ | ဘဏ်ငွေလွှဲ သို့မဟုတ် Conbini ဖြင့် ပေးချေရန် စောင့်ဆိုင်းနေသော အခြေအနေ။ |
| **入金済み** | Paid / ငွေပေးချေပြီး | ငွေပေးချေမှု အောင်မြင်ပြီးကြောင်း အတည်ပြုပြီးသောအခြေအနေ။ |
| **発送準備中** | Preparing for Shipment / ပို့ဆောင်ရန် ပြင်ဆင်နေ | ပစ္စည်းထုတ်ပိုးနေသည့် အခြေအနေ။ |
| **発送済み** | Shipped / ပစ္စည်းပို့ဆောင်ပြီး | ပို့ဆောင်ရေးယာဉ်ပေါ်တင်ပြီး Customer ထံသို့ ပို့ဆောင်နေသောအခြေအနေ။ |
| **注文取消し** | Order Cancelled / အော်ဒါပယ်ဖျက်ခြင်း | Customer သို့မဟုတ် Admin မှ အော်ဒါကို ဖျက်သိမ်းလိုက်ခြင်း (Stock ပြန်တက်မည်)။ |
| **購入処理中** | Processing / ဝယ်ယူဆဲ | Payment Gateway သို့ ငွေရှင်းနေဆဲ မပြီးပြတ်သေးသော ကြားကာလ အခြေအနေ။ |
| **返品** | Returned / ပစ္စည်းပြန်အမ်းခြင်း | ပစ္စည်းရောက်ပြီးနောက် Customer မှ ပြန်လည် အမ်းငွေ/ပစ္စည်းလဲလှယ်ခြင်း။ |

---

## ၃။ အော်ဒါပြင်ဆင်ခြင်းနှင့် ပို့ဆောင်ရေး Tracking No. ထည့်ခြင်း (受注詳細編集)

Admin Sidebar မှ **受注管理 -> 受注マスター** သို့သွားပြီး အော်ဒါတစ်ခုကို နှိပ်၍ အောက်ပါတို့ကို ပြင်ဆင်နိုင်ပါသည်-
1. **ပစ္စည်းအရေအတွက်နှင့် ဈေးနှုန်း ပြင်ဆင်ခြင်း**: ပစ္စည်းတိုးခြင်း၊ လျှော့ခြင်း၊ လျှော့ဈေး (Discount 値引き) ထည့်သွင်းခြင်း။
2. **ပို့ဆောင်ခ (送料) နှင့် ဝန်ဆောင်ခ (手数料) ပြင်ဆင်ခြင်း**။
3. **ပို့ဆောင်ရေး ခြေရာခံနံပါတ် (お問い合わせ番号 / Tracking Number)**: Yamato, Sagawa, Japan Post စသည့် ကုမ္ပဏီများ၏ Tracking Code ကို ထည့်သွင်းပြီး **発送完了メール (Shipping Notification Mail)** ကို တစ်ခါတည်း ပို့နိုင်ပါသည်။
4. **အစုလိုက် Status ပြောင်းခြင်း (一括ステータス変更)**: အော်ဒါများစွာကို Checkbox ဖြင့် ရွေးချယ်ပြီး တစ်ပြိုင်နက် "発送済み" သို့ ပြောင်းလဲနိုင်ပါသည်။

---

## ၄။ Customer စီမံခန့်ခွဲမှု (Customer Management - 会員管理)

Admin Sidebar မှ **会員管理 -> 会員マスター** သို့ သွားရောက်ပါ။

### Customer အခြေအနေများ (会員ステータス):
1. **本会員 (Active Member)**: Email Verification အောင်မြင်ပြီး အပြည့်အဝ အသင်းဝင်ဖြစ်သူ။
2. **仮会員 (Provisional Member)**: အသင်းဝင်ရန် လျှောက်ထားဆဲ (Email Verification Link မနှိပ်ရသေးသူ)။
3. **退会 (Withdrawn Member)**: အသင်းဝင်အဖြစ်မှ နှုတ်ထွက်သွားသူ (ဝယ်ယူမှု History ကို Audit အတွက် သိမ်းဆည်းထားသည်)။

### အဓိက စီမံနိုင်သော အချက်များ:
- **ဝယ်ယူမှုရာဇဝင် (Purchase History)**: Customer တစ်ဦးချင်းစီ ဝယ်ယူခဲ့ဖူးသော အော်ဒါများ၊ စုစုပေါင်း သုံးစွဲငွေပမာဏ (LTV - Lifetime Value)။
- **Point System (保有ポイント)**: Customer ၏ လက်ကျန် Point ပမာဏကို စစ်ဆေးခြင်းနှင့် လက်ဆောင် Point တိုးပေး/လျှော့ပေးခြင်း။
- **လိပ်စာစာရင်း (お届け先一覧)**: Customer မှတ်ပုံတင်ထားသော အပို ပို့ဆောင်ရမည့် လိပ်စာများ။

## ၅။ ဆိုင်အခြေခံ သတ်မှတ်ချက်များ (Store Settings - 基本設定)

Admin Sidebar မှ **設定 -> 店舗設定** တွင် အောက်ပါတို့ကို သတ်မှတ်နိုင်ပါသည်-

```
                       ┌─────────────────────────┐
                       │  店舗設定 (Store Settings)│
                       └────────────┬────────────┘
                                    │
       ┌────────────────────────────┼────────────────────────────┐
       ▼                            ▼                            ▼
┌──────────────┐             ┌──────────────┐             ┌──────────────┐
│  基本情報設定 │             │   税率設定   │             │ 配送・支払方法│
│ Shop Name,   │             │ Tax Rates    │             │ Shipping &   │
│ Address, Tel,│             │ 10% Standard │             │ Payment Gate-│
│ Email, Logo  │             │ 8% Reduced   │             │ ways (Stripe)│
└──────────────┘             └──────────────┘             └──────────────┘
```

1. **基本情報設定 (Basic Shop Info)**: ဆိုင်အမည်၊ ကုမ္ပဏီလိပ်စာ၊ ဖုန်းနံပါတ်၊ ဆက်သွယ်ရန် အီးမေးလ်။
2. **税率設定 (Tax Settings)**:
   - **標準税率 (Standard Tax Rate)**: 10% (အထွေထွေကုန်စည်များ)
   - **軽減税率 (Reduced Tax Rate)**: 8% (အစားအသောက်နှင့် သောက်စရာများ)
3. **配送方法設定 (Delivery Methods)**:
   - ပို့ဆောင်ရေး ကုမ္ပဏီ (Yamato Transport, Sagawa Express, Japan Post)
   - ခရိုင်အလိုက် ပို့ဆောင်ခ ဇယား (Prefecture Delivery Fee Matrix)
   - အချိန်အပိုင်းအခြား (Delivery Time Slots: 8-12, 14-16, 16-18, 18-20, 19-21)
4. **支払方法設定 (Payment Methods)**:
   - ဘဏ်ငွေလွှဲ (Bank Transfer / 銀行振込)
   - အိမ်ရောက်ငွေချေ (Cash on Delivery / 代金引換)
   - Credit Card Payment (Stripe / GMO / SB Payment စသည့် Plugin များနှင့် ချိတ်ဆက်အသုံးပြု)
