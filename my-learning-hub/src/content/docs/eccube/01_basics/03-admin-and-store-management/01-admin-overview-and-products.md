## Module 03 - အခန်း ၁: Admin Overview နှင့် ကုန်ပစ္စည်းစီမံခန့်ခွဲမှု (商品管理)

EC-CUBE ၏ Admin Dashboard (管理画面) သည် အွန်လိုင်းစတိုး၏ လုပ်ငန်းစဉ်အားလုံးကို ထိန်းချုပ်ရာ နေရာဖြစ်ပါသည်။ ဤအခန်းတွင် Admin Panel ၏ အဓိက အစိတ်အပိုင်းများနှင့် **ကုန်ပစ္စည်းစီမံခန့်ခွဲမှု (Product Management - 商品管理)** ကို အသေးစိတ် လေ့လာပါမည်။

---

## ၁။ Admin Panel ဖွဲ့စည်းပုံ အကျဉ်းချုပ် (Admin Structure)

Admin Dashboard သို့ ဝင်ရောက်ရန် URL မှာ `http://your-domain/admin/` ဖြစ်ပါသည်။

```
+-------------------------------------------------------------------------+
| [EC-CUBE LOGO]   [Shop Name]                     [Admin User] [Logout]  |
+-------------------+-----------------------------------------------------+
| SIDEBAR MENU      | MAIN CONTENT AREA                                   |
| ───────────────── | ─────────────────────────────────────────────────── |
| 📊 ホーム (Home)    | 📈 Sales Overview & Today's Orders                  |
| 🛒 受注管理 (Orders)| ⚠️ Stock Alerts (在庫切れアラート)                      |
| 📦 商品管理(Products| 🔔 Shop Notice / Important Info                     |
| 👥 会員管理(Customers                                                  |
| 🎨 デザイン管理(Design                                                  |
| 🧩 プラグイン(Plugins                                                  |
| ⚙️ 設定 (Settings) |                                                     |
+-------------------+-----------------------------------------------------+
```

### အဓိက Sidebar Menu များ-
1. **ホーム (Home)**: နေ့စဉ် အရောင်းစာရင်းနှင့် အော်ဒါအခြေအနေ Dashboard
2. **受注管理 (Order Management)**: အော်ဒါစာရင်း၊ အော်ဒါအသစ်ဖန်တီးခြင်း၊ စာရင်းပို့ခြင်း
3. **商品管理 (Product Management)**: ကုန်ပစ္စည်းများ၊ Category များ၊ 規格 (Variants) များ၊ Tags များ
4. **会員管理 (Customer Management)**: အသင်းဝင်စာရင်း၊ Customer အချက်အလက်များ
5. **コンテンツ管理 (Content Management)**: သတင်း/ကြေညာချက်များ (News), File Manager
6. **デザイン管理 (Design Management)**: Layout Editor, Block စီမံခြင်း၊ Template ပြင်ဆင်ခြင်း
7. **設定 (Settings)**: ဆိုင်အခြေခံအချက်အလက်များ၊ အခွန် (Tax)၊ ပို့ဆောင်ခ၊ Payment ချိတ်ဆက်မှုများ
8. **オーナーズストア (Owners Store / Plugins)**: Plugin များ Install ပြုလုပ်ခြင်းနှင့် Update စီမံခြင်း

## ၂။ ကုန်ပစ္စည်းစီမံခန့်ခွဲမှု (Product Management - 商品管理)

EC-CUBE တွင် ကုန်ပစ္စည်းတစ်ခု ထည့်သွင်းစီမံရာတွင် အောက်ပါအဓိက အစိတ်အပိုင်းများ ပါဝင်ပါသည်-

```
                          ┌───────────────────────────┐
                          │    Product (商品マスター)   │
                          └─────────────┬─────────────┘
                                        │
           ┌────────────────────────────┼────────────────────────────┐
           ▼                            ▼                            ▼
┌──────────────────────┐     ┌──────────────────────┐     ┌──────────────────────┐
│  Categories (カテゴリ) │     │     Tags (タグ)      │     │  規格 (Product Class) │
│ - Food > Snacks      │     │ - New Arrival        │     │ - Class 1: Size (S,M)│
│ - Clothes > Shirts   │     │ - Recommended (おすすめ)│     │ - Class 2: Color     │
└──────────────────────┘     └──────────────────────┘     └──────────────────────┘
```

## ၃။ ကုန်ပစ္စည်းအသစ် ထည့်သွင်းခြင်း (商品登録 - Product Registration)

Admin Sidebar မှ **商品管理 -> 商品登録** သို့ သွားရောက်ပါ။

### အဓိက ထည့်သွင်းရမည့် အချက်များ:
1. **商品名 (Product Name)**: ကုန်ပစ္စည်းအမည် (မဖြစ်မနေထည့်ရမည်)
2. **公開ステータス (Publish Status)**:
   - **公開 (Public)**: ဆိုင်တွင် ချက်ချင်းရောင်းချပြသမည်။
   - **非公開 (Private)**: မပြသသေးဘဲ Draft အဖြစ် သိမ်းဆည်းထားမည်။
   - **廃止 (Discontinued)**: ရောင်းချခြင်း ရပ်ဆိုင်းထားမည်။
3. **商品画像 (Product Images)**: ကုန်ပစ္စည်းဓာတ်ပုံများ (Drag & Drop ဖြင့် ပုံများစွာ တင်နိုင်သည်)
4. **商品説明一覧 (Brief Description)**: ကုန်ပစ္စည်းစာရင်း (List Page) တွင် ပြသမည့် စာသားတို
5. **商品説明詳細 (Detailed Description)**: ကုန်ပစ္စည်းအသေးစိတ်စာမျက်နှာ (Detail Page) တွင် ပြသမည့် စာသားရှည် (HTML tag များ သုံးနိုင်သည်)
6. **販売価格 (Selling Price - 税込/税抜)**: ရောင်းဈေး (အခွန်ပါ/အခွန်မပါ)
7. **通常価格 (Normal / Original Price)**: မူရင်းဈေး (လျှော့ဈေးပြသလိုပါက မျဉ်းသားပြသမည့် မူလဈေး)
8. **在庫数 (Stock Quantity)**:
   - **無制限 (Unlimited)**: အရေအတွက် အကန့်အသတ်မရှိ
   - **သတ်မှတ်အရေအတွက် (Quantity)**: လက်ကျန် အရေအတွက်
9. **商品コード (Product Code / SKU)**: ကုန်ပစ္စည်း ကုဒ်နံပါတ် (ဥပမာ: `PROD-001`)
10. **検索ワード (Search Keywords)**: User များ ရှာဖွေရာတွင် မိစေမည့် Keyword များ

## ၄။ 規格 (Product Classes / Variants) ဆိုတာဘာလဲ။

ကုန်ပစ္စည်းတစ်ခုတည်းတွင် Size (အရွယ်အစား) သို့မဟုတ် Color (အရောင်) ကွဲပြားမှုများ ရှိသည့်အခါ **規格 (Kikaku)** ကို အသုံးပြုပါသည်။

EC-CUBE တွင် အများဆုံး **規格1 (Class 1)** နှင့် **規格2 (Class 2)** ဟူ၍ Dimension (၂) ခုအထိ ပေါင်းစပ် Variant ထုတ်နိုင်ပါသည်-

```text
ဥပမာ: T-Shirt ကုန်ပစ္စည်းတစ်ခုအတွက်
- 規格1 (Class 1) = အရွယ်အစား (Size: S, M, L)
- 規格2 (Class 2) = အရောင် (Color: Red, Blue, White)

ထုတ်လုပ်မည့် ပေါင်းစပ်မှု (Matrix):
1. Size S x Red   (ဈေးနှုန်း: 1,000 JPY, Stock: 10, SKU: TSHIRT-S-RED)
2. Size S x Blue  (ဈေးနှုန်း: 1,000 JPY, Stock: 5,  SKU: TSHIRT-S-BLU)
3. Size M x Red   (ဈေးနှုန်း: 1,200 JPY, Stock: 8,  SKU: TSHIRT-M-RED)
... စသဖြင့် Variant တစ်ခုချင်းစီအလိုက် ဈေးနှုန်း၊ ပုံနှင့် Stock သီးခြားစီ သတ်မှတ်နိုင်ပါသည်။
```

### 規格 သတ်မှတ်နည်း အဆင့်ဆင့်:
1. **商品管理 -> 規格設定** သို့သွားပြီး 規格分類 (Class Name: ဥပမာ - Size) နှင့် 規格値 (Values: ဥပမာ - S, M, L) တို့ကို ကြိုတင် ဖန်တီးပါ။
2. ကုန်ပစ္စည်းစာရင်း (商品マスター) မှ သက်ဆိုင်ရာ ကုန်ပစ္စည်း၏ ညာဘက်ရှိ **規格設定** ခလုတ်ကို နှိပ်ပါ။
3. 規格1 နှင့် 規格2 ကို ရွေးချယ်ပြီး **規格一覧を設定** နှိပ်ပါ။
4. Matrix Table ပေါ်လာသည့်အခါ Variant တစ်ခုချင်းစီအတွက် ဈေးနှုန်းနှင့် Stock ထည့်သွင်းကာ Save ပြုလုပ်ပါ။

## ၅။ Category နှင့် Tag စီမံခန့်ခွဲမှု (カテゴリ・タグ管理)

### က။ Category စီမံခန့်ခွဲမှု (カテゴリ管理)
- **Multi-level Hierarchy**: အဆင့်ဆင့် ကွဲပြားသော Category သစ်ပင် (Tree) တည်ဆောက်နိုင်သည် (ဥပမာ: `အမျိုးသားဖက်ရှင် > အင်္ကျီ > တီရှပ်`)။
- **Drag & Drop Sorting**: Category အစီအစဉ်များကို Drag & Drop ဆွဲ၍ အလွယ်တကူ ရှေ့နောက် ပြောင်းလဲနိုင်ပါသည်။

### ခ။ Tag စီမံခန့်ခွဲမှု (タグ管理)
- ကုန်ပစ္စည်းများကို အထူးအမှတ်အသားပြုလုပ်ရန် သုံးပါသည် (ဥပမာ: `新着 (New Arrival)`, `おすすめ (Recommended)`, `限定品 (Limited Edition)`)။
- Frontend တွင် Badge သို့မဟုတ် Filter အဖြစ် ပြသရာတွင် အလွန်အသုံးဝင်ပါသည်။

## ၆။ ကုန်ပစ္စည်း CSV Export / Import (商品CSV登録・出力)

ကုန်ပစ္စည်း အရေအတွက် ထောင်နှင့်ချီ၍ တစ်ပြိုင်နက် ထည့်သွင်း/ပြင်ဆင်လိုသည့်အခါ **CSV စနစ်** ကို အသုံးပြုပါသည်:
- **商品CSV登録**: CSV ဖိုင်ကို Upload တင်၍ ကုန်ပစ္စည်းအများအပြား Bulk Insert / Update ပြုလုပ်ခြင်း။
- **商品CSV出力**: လက်ရှိ ကုန်ပစ္စည်းများအားလုံးကို CSV ဖိုင်အဖြစ် Download ရယူခြင်း။
