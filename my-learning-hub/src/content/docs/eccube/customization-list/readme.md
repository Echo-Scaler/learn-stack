## 🛠 လိုအပ်သော ကြိုတင်ပြင်ဆင်မှုများ

- EC-Cube 4.x ထည့်သွင်းပြီးသား ဖြစ်ရမည်
- PHP 8.x, Composer, Symfony CLI နားလည်ထားရမည်
- Terminal / Command Line အသုံးပြုတတ်ရမည်
