## 🎯 သင်ယူသူများအတွက် လမ်းညွှန်ချက် (How to Follow This Course)

1. **စတင်လေ့လာသူများ (Beginners):**
   - [01-docker-fundamentals-and-architecture.md](/devops/01_docker_core/01-docker-fundamentals-and-architecture/) မှ စတင်ဖတ်ပါ။
   - Docker Container ဆိုတာဘာလဲ၊ Virtual Machine နဲ့ ဘယ်လိုကွာခြားလဲဆိုတာကို သေချာနားလည်အောင် အရင်လုပ်ပါ။
   - CLI command များကို လက်တွေ့ terminal တွင် ရိုက်ထည့်ပြီး စမ်းသပ်ကြည့်ပါ။

2. **Web/Laravel Developers:**
   - အခန်း ၃၊ ၄၊ ၅ တို့ကို အခြေခံပြီးနောက် [07-php-laravel-nginx-mysql-redis-stack.md](/devops/01_docker_core/07-php-laravel-nginx-mysql-redis-stack/) နှင့် [10-real-world-laravel-docker-project.md](/devops/01_docker_core/10-real-world-laravel-docker-project/) သို့ တိုက်ရိုက်သွားရောက် လေ့လာနိုင်ပါသည်။
   - လက်တွေ့ `laravel-docker-project` folder ထဲရှိ Configuration များကို Run ကြည့်နိုင်ပါသည်။

3. **DevOps & Production Engineers (Advanced):**
   - [advanced-docker-kubernetes-production/](/devops/01_docker_core/advanced-docker-kubernetes-production/README/) သို့ သွားရောက်၍ Multi-Node Clustering, Kubernetes Architecture, High Availability, GitOps CI/CD နှင့် Production Manifests များကို လေ့လာနိုင်ပါသည်။

4. **Quick Command Lookup:**
   - Command တိုင်း၏ flag များ၊ ရှင်းလင်းချက်များနှင့် ဥပမာများကို [DOCKER-COMMANDS-REFERENCE.md](/devops/01_docker_core/DOCKER-COMMANDS-REFERENCE/) တွင် အချိန်မရွေး ရှာဖွေကြည့်ရှုနိုင်ပါသည်။
