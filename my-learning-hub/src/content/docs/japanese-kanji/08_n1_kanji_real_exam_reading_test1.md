## JLPT N1 漢字読み (Kanji Reading) လက်တွေ့စစ်ဆေးမှု စာမေးပွဲ (Test 1)

အောက်ပါ ဝါကျများရှိ မျဉ်းတားထားသော 漢字 ၏ မှန်ကန်သော အသံထွက်ကို (၁, ၂, ၃, ၄) ထဲမှ ရွေးချယ်ပါ။ အဖြေတစ်ခုချင်းစီအတွက် **Romaji နှင့် မြန်မာလို အသေးစိတ် ရှင်းလင်းချက်** ကို မေးခွန်းအောက်တွင် ဖော်ပြပေးထားပါသည်။

---

### မေးခွန်း ၁
政府は国民に対して、感染症予防への注意を**促した**。
1. おどした (*odoshita*)
2. うながした (*unagashita*)
3. そそのかした (*sasonokashita*)
4. はたした (*hatashita*)

<details>
<summary>▶ အဖြေနှင့် ရှင်းလင်းချက် ကြည့်ရန်</summary>

**အဖြေမှန်: ၂. うながした (unagashita)**  
- **促す (うながす / unagasu)**: တိုက်တွန်းနှိုးဆော်သည် / အရှိန်မြှင့်တင်ရန် လှုံ့ဆော်သည်။
- ❌ ၁. 脅した (*odoshita* - ခြိမ်းခြောက်ခဲ့သည်)
- ❌ ၃. 唆した (*sosonokashita* - သွေးထိုးလှုံ့ဆော်ခဲ့သည်)
- ❌ ၄. 果たした (*hatashita* - ပြီးမြောက်အောင်မြင်ခဲ့သည်)
</details>

### မေးခွန်း ၂
最新のデータは、景気の回復を強く**示唆**している。
1. じしゃ (*jisha*)
2. じさ (*jisa*)
3. ししゃ (*shisha*)
4. しさ (*shisa*)

<details>
<summary>▶ အဖြေနှင့် ရှင်းလင်းချက် ကြည့်ရန်</summary>

**အဖြေမှန်: ၄. しさ (shisa)**  
- **示唆 (しさ / shisa)**: သွယ်ဝိုက်ညွှန်ပြခြင်း / အရိပ်အမြွက်ပြခြင်း။
- `示` ၏ Onyomi သည် `シ (shi)` ဖြစ်ပြီး `唆` ၏ Onyomi သည် `サ (sa)` ဖြစ်သည်။
</details>

### မေးခွန်း ၃
長年の夢がようやく叶い、**感慨**無量である。
1. かんがい (*kangai*)
2. かんかい (*kankai*)
3. こうがい (*kōgai*)
4. ごうかい (*gōkai*)

<details>
<summary>▶ အဖြေနှင့် ရှင်းလင်းချက် ကြည့်ရန်</summary>

**အဖြေမှန်: ၁. かんがい (kangai)**  
- **感慨 (かんがい / kangai)**: ရင်ထဲနက်ရှိုင်းစွာ ခံစားရသော စိတ်ခံစားမှု။
- `感慨無量 (かんがいむりょう)`: ရင်ထဲတွင် ပြောမပြနိုင်လောက်အောင် ခံစားချက်များ ပြည့်လျှံနေခြင်း။
</details>

### မေးခွန်း ၄
彼は投資で大損したが、全く**懲りて**いない様子だ。
1. こりて (*korite*)
2. すりて (*surite*)
3. たりて (*tarite*)
4. ねりて (*nerite*)

<details>
<summary>▶ အဖြေနှင့် ရှင်းလင်းချက် ကြည့်ရန်</summary>

**အဖြေမှန်: ၁. こりて (korite)**  
- **懲りる (こりる / koriru)**: ကျရှုံးမှု သို့မဟုတ် အမှားကြောင့် နာကျင်မှတ်သားသွားသည်။
</details>

<details>

### မေးခွန်း ၆
関係法令の**遵守**を全社員に徹底させる。
1. じゅんしゅ (*junshu*)
2. そんしゅ (*sonshu*)
3. じゅんす (*junsu*)
4. しょうしゅ (*shōshu*)

<details>
<summary>▶ အဖြေနှင့် ရှင်းလင်းချက် ကြည့်ရန်</summary>

**အဖြေမှန်: ၁. じゅんしゅ (junshu)**  
- **遵守 (じゅんしゅ / junshu)**: ဥပဒေစည်းမျဉ်းများကို တသွေမတိမ်း လိုက်နာစောင့်ထိန်းခြင်း။
</details>

過去の失敗に**鑑み**、計画を根本から見直す。

2. うらみ (*urami*)
3. かんがみ (*kangami*)

<summary>▶ အဖြေနှင့် ရှင်းလင်းချက် ကြည့်ရန်</summary>

### မေးခွန်း ၁၀
双方の債権と債務を**相殺**することに合意した。
1. そうさつ (*sōsatsu*)
2. そうさい (*sōsai*)
3. しょうさつ (*shōsatsu*)
4. しょうさい (*shōsai*)

<details>
<summary>▶ အဖြေနှင့် ရှင်းလင်းချက် ကြည့်ရန်</summary>

**အဖြေမှန်: ၂. そうさい (sōsai)**  
- **相殺 (そうさい / sōsai)**: တစ်ခုနှင့်တစ်ခု အရှုံးအမြတ် ကျေအေးကာမိစေခြင်း။
- `殺` ကို ဤနေရာတွင် ပုံမှန် `さつ (satsu)` မဖတ်ဘဲ `さい (sai)` ဟု အထူးဖတ်ရပါမည်။
</details>
