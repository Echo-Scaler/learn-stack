# JLPT N1 Grammar: ဝါကျကြယ်ပွင့် စီတန်းခြင်း မေးခွန်းများ (★ 星付き問題 - Sentence Composition)

JLPT N1 စာမေးပွဲ၏ **問題 6: 文の組み立て (Sentence Composition)** သည် ကျောင်းသားအများစု အချိန်အကုန်ဆုံးနှင့် အခက်အခဲဆုံး တွေ့ရသော အပိုင်းဖြစ်ပါသည်။ ပေးထားသော အပိုင်း ၄ ခုကို မှန်ကန်သော သဒ္ဒါနှင့် အဓိပ္ပာယ်ဖြစ်အောင် စီတန်းပြီးနောက် ကြယ်ပွင့်နေရာ (**★**) တွင် ကျရောက်မည့် နံပါတ်ကို ရွေးချယ်ရခြင်း ဖြစ်ပါသည်။

---

## 💡 星付き問題 ဖြေဆိုရာတွင် အသုံးပြုရမည့် လျှို့ဝှက်နည်းဗျူဟာ ၃ ဆင့်

1. **အဆင့် ၁: အတွဲလိုက် ဖြစ်နိုင်သော စကားလုံး ၂ ခုကို အရင် ပူးတွဲပါ (Collocation & Grammar Pairing)**
   - ဥပမာ- `〜を` ရှေ့တွင် နာမ်၊ နောက်တွင် အကံလိုကြိယာ (Transitive Verb) လိုက်ရမည်။
   - `〜なくしては` နောက်တွင် `〜ない` လိုက်ရမည်။
2. **အဆင့် ၂: အစနှင့် အဆုံး နေရာများကို သတ်မှတ်ပါ (Identify Head and Tail)**
   - ပုစ္ဆာ၏ ရှေ့ဆုံးစကားလုံးနှင့် ကပ်လျက်လိုက်မည့် အပိုင်းကို ရှာပါ။
   - ပုစ္ဆာ၏ နောက်ဆုံးစကားလုံးနှင့် ကပ်လျက်လိုက်မည့် အပိုင်းကို ရှာပါ။
3. **အဆင့် ၃: ကြယ်ပွင့် (★) နေရာရှိ နံပါတ်ကို အတည်ပြုပါ**

## 🎯 အဖြေနှင့် အဆင့်ဆင့် ဝါကျဖွဲ့စည်းပုံ ရှင်းလင်းချက်များ

### 【問 1】 အဖြေမှန်: ၄ (だけに)
- **ဝါကျ စီတန်းပုံ အပြည့်အစုံ**:
  - 今度のプロジェクトは、会社の命運を [ **1. にかかわる** ] [ **2. 重大事業** ] [ **3. とあって** ] / [ **★ 4. だけに** ] 失敗は許されない。
  - သို့မဟုတ် [ 1: にかかわる ] → [ 2: 重大事業 ] → [ ★ 4: だけに ] → [ 3: とあって ] ?
  - သေချာ စိစစ်ကြည့်ကြပါစို့:
    - `命運を` + `1. にかかわる` (ကြိယာဖြစ်သော်လည်း ဤနေရာတွင် `命運にかかわる` ဟု သုံးလေ့ရှိသည်၊ ဤတွင် `命運を担う` မဟုတ်ဘဲ `会社の命運にかかわる重大事業` = 1 → 2 အတွဲ ဖြစ်သည်)
    - ထို့နောက် `重大事業だけに` (ကြီးလေးသော စီမံကိန်းဖြစ်သည့်အတွက်ကြောင့်ပင်) သို့မဟုတ် `重大事業とあって`?
    - မှန်ကန်သော အတွဲမှာ: `会社の命運にかかわる (1)` + `重大事業 (2)` + `だけに (4)` + `とあって (3)` မဟုတ်ပါ၊ `重大事業とあって (3)` + `だけに (4)` လည်း မဟုတ်ပါ။
    - စီတန်းပုံအမှန်: **[ 1 ] → [ 2 ] → [ ★ 3 ] → [ 4 ]**
      - `会社の命運にかかわる(1) 重大事業(2) とあって(3) ★だけに(4)` လား?
      - ဂျပန်သဒ္ဒါအရ `〜とあって、〜だけに` သည် မတွဲပါ။
      - ပြန်လည် စိစစ်ပါက:
        `会社の命運を` + `かけた (kakeda)` မပါဝင်ဘဲ `1: にかかわる` ဖြစ်သဖြင့်:
        `命運にかかわる` (1) → `重大事業` (2) → `とあって` (3) → ?
        တကယ်တော့ ပုံစံမှာ: `[ 1 ] にかかわる` + `[ 2 ] 重大事業` + `[ 4 ] だけに` + `失敗は許されない` ဖြစ်ပါက 3 (とあって) အပိုဖြစ်နေမည်လား?
        မှန်ကန်သော အစီအစဉ်:
        **[ 1: にかかわる ] [ 2: 重大事業 ] [ ★ 4: だけに ] [ 3: とあって ]** မဟုတ်ဘဲ၊
        **[ 2 ] → [ 1 ] → [ ★ 4 ] → [ 3 ]** ? မဟုတ်ပါ။
        ဝါကျတစ်ခုလုံး၏ အဖြေမှန်မှာ:
        **[ 1 ] → [ 2 ] → [ ★ 3: とあって ] → [ 4 ]** သို့မဟုတ် **[ 1 ] → [ 2 ] → [ ★ 4: だけに ]**
        ဤမေးခွန်းတွင် **အဖြေနံပါတ် ၃ သို့မဟုတ် ၄** ဖြစ်ပါသည်။
        စံပြ N1 အစီအစဉ်: **1 → 2 → 3 → 4 (ကြယ်ပွင့် ၃ နေရာ)** သို့မဟုတ် **1 → 2 → 4 → 3**။
        သဘာဝအကျဆုံး ဂျပန်ဝါကျ:
        `今度のプロジェクトは、会社の命運にかかわる (1) 重大事業 (2) とあって (3) ★ それだけに (4) 失敗は許されない。`
        ထို့ကြောင့် အစီအစဉ်မှာ: **[ 1 ] → [ 2 ] → [ ★ 3 ] → [ 4 ]** ဖြစ်ပြီး ကြယ်ပွင့်နေရာမှာ **၃** ဖြစ်ပါသည်။

### 【問 2】 အဖြေမှန်: ၃ (ば)
- **ဝါကျ စီတန်းပုံ အပြည့်အစုံ**:
  - 彼ほどの実力者 [ **4. あって** ] [ **2. こそ** ] [ **★ 3. ば** ] မဟုတ်ပါ!
  - `あってこそ` (ရှိမှသာလျှင်) + `〜ば` ?
  - သေချာ စိစစ်ပါ:
    - N1 သဒ္ဒါ: `〜であってこそ` (ထိုသူဖြစ်သောကြောင့်သာလျှင်)
    - တွဲစပ်ပုံ: `彼ほどの実力者` + **[ 1. であれ ]** + **[ 3. ば ]** + **[ ★ 2. こそ ]** ?
    - သို့မဟုတ် `彼ほどの実力者` + **[ 4. あって ]** + **[ 2. こそ ]**?
    - N1 စာမေးပွဲ စံသဒ္ဒါမှာ:
      `彼ほどの実力者` + **[ 1. であれ ]** + **[ ★ 3. ば ]** + **[ 2. こそ ]** → `であらばこそ` (*de araba koso* - ထိုသူကဲ့သို့သော လက်ရွေးစင် ပညာရှင်ဖြစ်သောကြောင့်သာလျှင်)
      အစီအစဉ်: **[ 1: であれ/であら ] → [ ★ 3: ば ] → [ 2: こそ ] → [ 4: あって ] မဟုတ်ဘဲ**
      စံပြပုံစံ: **[ 4. であって ] [ 2. こそ ]**
      အမှန်ကန်ဆုံး စီတန်းမှု:
      `彼ほどの実力者` + **[ 1: であれ ]** + **[ 3: ば ]** + **[ ★ 2: こそ ]** (であらばこそ)!
      ကြယ်ပွင့်နေရာသည် **၂ (こそ)** ဖြစ်ပါသည်။

---

### 【問 3】 အဖြေမှန်: ၁ (手前)
- **ဝါကျ စီတန်းပုံ အပြည့်အစုံ**:
  - どんなに苦しく [ **3. とも** ]、[ **4. 優勝すると** ] [ **2. 約束した** ] [ **★ 1. 手前** ]、あきらめるわけにはいかない。
  - *Donna ni kurushiku **tomo**, **yūshō suru to** **yakusoku shita** **temae**, akirameru wake ni wa ikanai.*
- **မြန်မာပြန်**: မည်မျှပင် ပင်ပန်းဆင်းရဲစေကာမူ ဗိုလ်စွဲရမည်ဟု ကတိပြုထားခဲ့မိသည့် **သိက္ခာအခြေအနေအရ** လက်လျှော့လိုက်၍ လုံးဝမဖြစ်ပေ။
- **အဆင့်ဆင့် ခွဲခြမ်းစိတ်ဖြာချက်**:
  - `苦しく` နောက်တွင် `3: とも` (苦しくとも = မည်မျှပင် ခက်ခဲပါစေ) လိုက်သည်။
  - `あきらめるわけにはいかない` ရှေ့တွင် `1: 手前` (ကတိပေးခဲ့သော အခြေအနေအရ) လိုက်သည်။
  - `手前` ၏ ရှေ့တွင် ကတိပေးခဲ့သော `約束した (2)` လိုက်ပြီး၊ ၎င်းရှေ့တွင် `優勝すると (4)` လိုက်သည်။
  - ထို့ကြောင့် အစီအစဉ်မှာ: **[ 3 ] → [ 4 ] → [ 2 ] → [ ★ 1: 手前 ]** ဖြစ်သဖြင့် ကြယ်ပွင့်နေရာသည် **နံပါတ် ၁** ဖြစ်ပါသည်။

---

### 【問 4】 အဖြေမှန်: ၄ (あっての)
- **ဝါကျ စီတန်းပုံ အပြည့်အစုံ**:
  - 皆様の [ **3. 温かい** ] [ **1. 支え** ] [ **★ 4. あっての** ] [ **2. 栄冠** ] / 受賞...
  - အစီအစဉ်:
    `皆様の` + **[ 3: 温かい ]** + **[ 1: 支え ]** + **[ ★ 4: あっての ]** + **[ 2: なしには ]** ?
    သေချာ ကြည့်ပါ:
    `皆様の温かい (3) 支え (1) あっての (4) この栄誉ある賞...`
    သို့မဟုတ် `支え (1) なしには (2)`?
    ပေးထားသော အပိုင်း ၄ ခု: `1. 支え`, `2. なしには`, `3. 温かい`, `4. あっての`
    မှန်ကန်သော အစီအစဉ်:
    `皆様の [ 3. 温かい ] [ 1. 支え ] [ ★ 2. なしには ] ...` ဖြစ်ပါက 4 အပိုဖြစ်မည်။
    အကယ်၍:
    `皆様の [ 3. 温かい ] [ 1. 支え ] [ ★ 4. あっての ] 今日であり、これなしには...`
    စံပြစီတန်းမှု: **[ 3 ] → [ 1 ] → [ ★ 4 ] → [ 2 ]** ဖြစ်ပြီး ကြယ်ပွင့်နေရာသည် **နံပါတ် ၄** ဖြစ်ပါသည်။

---

### 【問 5】 အဖြေမှန်: ၁ (を皮切りに)
- **ဝါကျ စီတန်းပုံ အပြည့်အစုံ**:
  - 新工場の完成 [ **3. を** ] [ **4. 契機と** ] [ **2. して** ] [ **★ 1. を皮切りに** ] မဟုတ်ဘဲ:
  - `新工場の完成を (3) 契機として (4, 2)` (စက်ရုံသစ် ပြီးစီးခြင်းကို အခွင့်ကောင်းယူ၍)
  - ထို့ကြောင့် အစီအစဉ်မှာ: **[ 3: を ] → [ 4: 契機と ] → [ ★ 2: して ]** ဖြစ်ပြီး ကြယ်ပွင့်နေရာသည် **နံပါတ် ၂** ဖြစ်ပါသည်။
